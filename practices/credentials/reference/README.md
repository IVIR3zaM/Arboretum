# reference/

A vendor snapshot of the external documentation and infrastructure configuration the services in
this repository depend on: the specifications they implement, the contracts of the services they
call, and the configuration of the infrastructure they run against. The owning teams maintain the
originals; this copy is synced from them.

This directory is read-only. Do not edit it — local changes are overwritten on the next sync.
