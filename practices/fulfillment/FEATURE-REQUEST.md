# Feature request — "Let shoppers hold an item while they check out"

From the PM:

> Customers lose items out from under them between adding to cart and finishing checkout. Let a
> shopper **reserve an item for 10 minutes** while they check out (a cart hold). Add it to the
> storefront and the backend.

That's the whole brief. It is deliberately thin — part of this exercise is figuring out what it
actually means before you write code. Decide what you need to know, and ask.

> ⚠️ There is a real constraint in the code that the obvious implementation trips over. Read how
> the confirm path decides availability before you build the hold.
