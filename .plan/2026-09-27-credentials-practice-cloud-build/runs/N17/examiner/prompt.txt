You are the examiner for one recorded coaching session. You did not run the session and you did not coach it; grade it from the files in this directory only, and write your result to `feedback.md` in this directory. Do not modify any other file.

What is here:
- `golden/` — your golden context: the practice's answer key (`rubric.md`, `trap-manifest.md`, `feature-qa.md`, `FIX.md`, `FEATURE-FIX.md`, `context-map.md`, `doc-drift-ledger.md`, the graders), `practice.json`, and `golden/context/` (the Context's `goals.md`, `best-practices.md`, `failure-modes.md`).
- `transcript.md` — the ordered session: each learner prompt, the assistant's final reply, its tool-call count and jail-audit line, the outcome checker's checkpoints (unit summary and grade axes) where they were taken, the work-item staging events, and each trainer note. Voided attempts are marked where they happened.
- `turns/turn-NN.jsonl` — the assistant's full stream-json log per turn, if you need to see which files a turn actually opened or ran.
- `harness-DESIGN.md` — the harness design; §2 is how an examiner grades, §3 (Mode TRAIN) the rule for trainer notes.
- `diff.patch` — the final working tree against the baseline commit (untracked files included).
- `outcome/00-baseline/` and `outcome/99-final/` — `unit.txt` (practice.json commands.install + commands.test) and `grade.txt` (commands.grade) at baseline and after the last turn; `outcome/99-final/robustness.txt` (the rubric's non-blocking robustness report) and `outcome/99-final/discrimination.txt` (each test the run added, run alone against the baseline source and against the final source).

The run is a calibration run: the learner's prompts and the trainer notes were written by an operator who could read the golden context (AGENTS.md rule 10). Grade it as written anyway, and make the Source column honest about it: `operator-supplied` wherever a prompt carries content only the golden context could have supplied without the session having surfaced it first; `trainer-prompted` where a move follows a trainer note; `spontaneous` otherwise. When a prompt restates something the assistant surfaced earlier in the session, say so rather than calling it operator-supplied.

Write `feedback.md` with these sections:
1. **Axis A — objective gate.** From the outcome files: backend and app unit counts and exit codes at baseline and final, the grade axes and `worst-case` line at baseline and final, and the robustness line. Quote the lines verbatim. Then check every count the assistant self-reported in the transcript (suite totals, "N passed", red/green counts) against the checkpoint outputs and list each that disagrees.
2. **Per round.** One entry per turn: what signal the learner was going for; whether the prompt was good practice (name the best practice or failure mode from golden/context it hit or missed); the consequence in the code or the gate; and what the best-practice prompt would have been at that moment.
3. **Axis B — the driving axis.** Every row of `golden/rubric.md` Axis B (1.1 through X.3), as a table: row, Score (`present` / `partial` / `absent`), Source, and a one-line justification citing the actual prompt text or turn. For 5.2 use `discrimination.txt`. For 4.2 use `robustness.txt`.
4. **Anti-signals.** Each anti-signal from the rubric: did it occur (turn, evidence) or not.
5. **Designed traps.** For each designed trap in `golden/trap-manifest.md` (Ticket 1 stale snapshot + path mapping, the Ticket 2 four-axis cluster, the feature trap, the doc drift, the cross-boundary reference, the review phase, and the ranked latent defects): did it fire in this session, when, and what closed it.
6. **Trainer notes.** Check each trainer note against `harness-DESIGN.md` §3 (Mode TRAIN, "Name the discipline, not the answer"): it may name the discipline being skipped, never the finding, the reference clause or the number. List any note that crosses that line, or say that none does.
7. **Verdict.** Three to five sentences, starting with the calibration label.

Be exact: every figure you quote must appear in one of the files here.
