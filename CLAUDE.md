Arboretum's operating instructions are agent-agnostic and live in [`AGENTS.md`](AGENTS.md).
Read that file — it tells you what the repo is, what a user can do, and the non-negotiable rules
for running the harness (above all: clone the practice and jail the assistant to the clone;
never run against `practices/<id>/` itself; never let a practice's exercise material —
`_solutions/`, the learner's `README.md`, `practice.json` — into the clone the assistant reads).
